# 震荡板：接口与代码说明
版本：V0.9 / H0 | 日期：2026-10-04 | 当前：参数、按键与面板逻辑已通过主机测试

## 当前需求（本节取代旧候选，历史见03）
主控STM32F334R8T6（预算排除G474）；C语言；HRTIM仅使用8路真实低有效PWM，剩余2路禁止PWM输出。
高频N档对应N路同相同宽PWM；未投入路高电平。八路边沿同步必须上板验证，不能凭主机计算结果宣称通过。
正常程序0～9各有独立参数，共10组；碰丝“-”独立1组，总共11组。两模式切换不保存。
所有组同范围：高频1～8档、脉宽2～99µs、脉间2～32倍。
低电平时间Wµs，高电平W×Mµs，周期W×(M+1)µs。有效周期范围6～3267µs。
原G030的引脚、TIM1/TIM3方案及ARR/CCR公式不用于F334 HRTIM；F334当前资源核对见文末H0。

## 面板与输入
一片TM1637六位显示，当前按示例从左到右：序号/横杠、功放、脉宽十位/个位、脉间十位/个位；此前口述位号方向有歧义，实物位映射须在显示阶段验收。
序号小数点为保存状态；实际参数/正常序号改变熄灭，最后变化后2.5秒请求保存，真正写入且校验成功才常亮。
正常与碰丝未保存修改统一纳入保存快照，切模式不重置保存倒计时。
按键1～9：序号+、序号-、高频+、高频-、脉宽+、脉宽-、脉间+、脉间-、碰丝。
均低有效；前8键长按连发；碰丝每次按压只切一次，长按不重复。
正常已保存且无操作120秒仅显示降至最低亮度，任何按键恢复并执行原功能；碰丝不休眠。
亮度/模式切换本身不触发保存，不停止PWM。
“剩余两路禁用”是HRTIM输出要求，不代表原第10路输入已被定义或是启动脚；当前按9个已定义按键开发。

## 实现默认及仍待确认
- 单步1、边界停止不绕回、碰丝序号键无效、固定前N路投入、2.5秒保存：实现默认，文档集中记录。
- 已确认上电即输出，用户外部有保护。硬件层完成初始化和参数校验后自动按保存的正常序号输出，不等待外部开启命令；复位/初始化过渡期先保持无效。当前纯逻辑模块不操作PWM。
- 11组出厂参数没有给定；调用者必须传入参数表。测试样例不能当出厂值。
- 物理引脚、晶振/时钟树、驱动电平、下载方式未冻结，不能画板套旧表。

## 参数模块接口
| 接口 | 输入/返回 | 约束 |
|---|---|---|
| osc_profile_valid / osc_image_valid | 参数/整表→bool | 拒绝非法值，不悄悄写成可用功率参数 |
| osc_params_init | 整表、是否已持久化、毫秒→bool | 进入正常模式；默认参数未真正保存时persisted=false |
| osc_params_current | 上下文→只读当前组指针 | 未初始化返回NULL |
| osc_params_select | 正常序号0～9、时间→是否改变 | 碰丝无效；实际变化标脏 |
| osc_params_toggle_mode | 上下文→是否完成 | 只切内存模式，不影响脏标记及计时 |
| osc_params_adjust | 字段、+1/-1、时间→是否改变 | 调当前组；无变化不重启保存计时 |
| osc_profile_pulse | 参数→逻辑波形 | 必须检查返回值；成功后读取低/高/周期和掩码 |
| osc_params_save_due | 时间→bool | 脏且无保存进行中，并已静默2500ms |
| osc_params_begin_save | 时间→参数快照和版本令牌 | 由未来存储层执行实际序列化/写入 |
| osc_params_finish_save | 令牌、写入校验结果、时间 | 旧快照完成不清除新修改；失败延时重试 |
| osc_params_is_saved | 上下文→bool | 可供小数点逻辑使用，目前无显示驱动 |

上下文只允许主循环串行调用，不是线程/中断安全接口，不允许直接修改公开结构成员。
持久化快照不含碰丝/正常模式；含10组正常、碰丝组和当前正常序号。
结构体仅为内存表示，禁止未来直接按sizeof裸写Flash；存储层另定义版本、编码、CRC和掉电提交。
channel_mask是逻辑位0～7，不是HRTIM寄存器使能掩码；剩余输出仍需板级显式禁用。
millisecond计时使用uint32差值，调用间隔须短于一次完整回绕周期。

头文件在firmware/include，源文件在firmware/src；物理GPIO尚未配置，不能按这些文件找改脚定义。
主循环先初始化params，再调用osc_panel_init；循环osc_panel_poll后可取frame供未来显示驱动使用。
poll返回“参数或模式有变化”，不是直接启动/停止PWM命令；未来脉冲驱动仍按统一时序提交完整参数。
按键默认策略：开机按住不触发，稳定松开20ms后才接受；同一对加减同时按则不调参；不同字段可以同时调整。
碰丝事件同一扫描优先，其他按住的调参键锁定到松开；轮询延迟不一次补发大量步骤。
保存成功后的首次轮询起计120秒；按键按住/消抖中、不在已保存态、碰丝模式均保持亮。
变暗不改变参数或保存小数点状态；第一次按键不吞功能，边界无变化也恢复亮度。

### 时钟与计数范围
选用方案：8MHz HSE → PLL ×9 → SYSCLK/HCLK 72MHz；APB1 /2、APB2 /1；RCC_CFGR3.HRTIM1SW=0取APB定时器时钟72MHz；HRTIM CKPSC=7（DIV4），实际计数18MHz。不使用DLL高分辨率模式，不等待DLL校准完成。
RM0364 8.2.11明确允许APB时钟模式，限制CKPSC必须≥5；此处7满足。注意DIV4是对HRTIM输入时钟，不是对CPU之外的PLL×2时钟；不能选错时钟源。
由此每微秒18个整数计数：低脉宽=18W、高脉间=18WM、周期=18W(M+1)，不存在整数微秒的量化舍入；绝对时序误差仍来自晶振等实际硬件。
周期最小108、最大58806；99µs/32倍对应低1782、高57024、周期58806，未超16位范围。20µs/05倍对应低360、高1800、周期2160。
这里是设计计数值，不是套用普通TIM的ARR=周期−1；HRTIM最终PER/比较寄存器规则在H3实现时逐项核对。
发现的配置陷阱：PLL×2的144MHz配最大DIV4也仍为36MHz，最长周期需要117612计数，超16位；128MHz配DIV4亦需104544。不得复制最高分辨率示例后把计数截成uint16。

### 八路同步实现方向
HRTIM A/B/C/D的两个输出可分别选择置位/复位事件，不需要把其中四路作为对外互补波形。八路统一以主定时器周期和比较事件定义脉冲，并统一配置有效极性为低；关闭死区/互补逻辑，避免把四路变成相反相位。
共用同一硬件事件源是同步设计依据，不使用中断逐个GPIO翻转。低有效的“置位”是内部有效态，经输出极性转换后引脚应为低；必须在H3单路测试中先确认。
路数N仍对应前N路投入，未投入路保持高；档位/脉宽/模式更新必须成组提交。寄存器预装载、更新时机、启用/停用时避免半脉冲的具体步骤留在H3核对与实现，当前不宣称已解决实测毛刺。
