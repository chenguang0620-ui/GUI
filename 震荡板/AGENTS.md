# 震荡板开发规则
- 用户明确指定项目放在仓库根目录“震荡板/”，不得擅自移动。
- 先读01_接口与代码说明.md、02_人机共读计划书.md、03_AI接管与修改记录.md。
- 一次只实施一个可验收的小步骤并记录提交。用户于2026-10-04 00:38授权澄清后由AI逐步完成C代码；可自主推进有软件验证依据的小步，不一次无记录生成全工程。需要真实上板结论的步骤保留待用户验收，不虚构通过。
- 修改代码前先更新本步目标、新增/修改文件清单、接口影响和验收方法。
- 完成每步后同步三份长期文档，记录实际改动、已知问题、验证证据、回退基线、下一步。
- 状态机组织业务，显示、输入、调度分层；不使用无限等待，不把所有输入当按键。
- 未确认的型号、引脚、电平、滤波、时序、功率参数明确标待定，不凭经验冒充用户确认。
- 计划模块不代表已实现接口；编译通过不代表上板通过；风险推测不代表实际踩坑。
- 当前S0澄清：主控STM32F334R8T6，使用C。关键业务问题确认后开始逐步实施；旧G030引脚作废。碰丝键一次按压只切换一次，显示休眠不应停止PWM。
