# 电火花数控穿孔机上位机

PyQt6 项目。当前版本为**离线仿真**：已实现 G 代码校验、孔位预览、全机床手动页、独立找中与 G54 补偿页、单孔穿孔状态流程、反馈模式设置与事件日志。真实设备通信和放电控制仍需与 STM32F407 固件联调。

## 启动

```bash
git clone https://github.com/chenguang0620-ui/GUI.git
cd GUI/gpt代码项目/穿孔机项目
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/edm-drill
```

Windows PowerShell 在项目目录中运行 `py -m venv .venv`、`.\.venv\Scripts\python.exe -m pip install -e .`、`.\.venv\Scripts\edm-drill.exe`。从源码运行时设置默认保存在项目 `data/settings.json`；安装包运行时保存在用户目录 `.local/share/edm-drill/settings.json`。可用环境变量 `EDM_DRILL_DATA` 指定其他数据目录。

## 体验完整流程

1. 主窗口按三栏显示：左侧坐标与设备状态，中间十二孔加工路径，右侧深度、加工状态和时间。默认十二孔程序随安装包提供，首页直接显示孔位；黄环表示当前孔，绿勾表示完成，蓝环表示选中。点击孔位可查看坐标，孔位图支持缩放和平移。
2. 到「机床手动」依次执行 Z 回零、XY 回零。此页提供 X/Y/Z 定长点动、目标快移、停止手动运动，以及冲液、电极旋转、放电脉冲手动开关。接触高度仅用小步距点动；XY 目标快移须先抬起 Z。
3. 到「找中 / 补偿」输入铜管实测外径，手动接触工件的 X−/X+/Y−/Y+ 边缘后分别记录位置。每轴可选单边设零或对边中心，输入有符号附加补偿，预览旧/新 G54 读数后确认应用。双边中心的铜管半径会抵消；单边按接触方向加减半径。应用后触碰记录清空。
4. 回到「机床手动」确认工件表面 Z0。默认已校验十二孔演示程序；可在「程序库」编辑 G 代码并重新生成孔位图。修改后首页会提示孔位图仍是上次校验版本，重新校验前禁止启动；作业暂停时程序编辑也会锁定。
5. 底部“循环启动 / 继续”执行作业；“暂停”在当前孔退刀后生效；“单段”每加工一孔暂停。
6. 在「工艺 / 诊断」可选择编码器、光栅尺、双闭环；光栅尺分辨率默认 5 µm/计数，保存后须重新确认 Z0。

找中页调整的是 **G54 工作零点**，不改写 G 代码，也不执行 G41/G42 加工路径刀补。触碰由操作者现场确认，当前没有自动探针。LinuxCNC 的 G54 写入会持久保存；重新装夹后要重新找中。离线模拟器可演示手动输出，实机冲液、旋转和放电脉冲输出只有下位机声明已接入时才可操作。

测试：`.venv/bin/python -m pytest -q`。
