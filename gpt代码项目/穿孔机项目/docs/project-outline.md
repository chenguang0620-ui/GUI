# 数控电火花穿孔机系统大纲

版本：v0.1，按当前已知硬件与需求整理。

## 一、目标与已知硬件

目标是制作一套 PyQt6 上位机与 STM32F407 下位机配合的数控穿孔系统。上位机负责作业编辑、校验、显示、设置和记录；下位机负责运动输出、Z 轴反馈控制、放电间隙响应与安全停机。

已知硬件：Z 轴为步进电机，驱动器被称作 `BT6600`（铭牌型号待核对，可能为 `TB6600`）；编码器和光栅尺都是 TTL 电平的增量型信号；光栅尺标称分辨率 5 µm，软件允许后期修改。传感器 A/B/Z 相、编码器计数、丝杠导程、驱动器脉冲电气要求及全部联锁信号仍待确认。

## 三、主要控制逻辑

1. **加工前**：PC 在机床手动页先发 Z 回零、再发 XY 回零，按需点动/快移并控制冲液等辅助输出；找中页记录人工碰边，计算铜管中心与附加补偿，按轴写入 G54；最后确认工件表面 Z0。STM32F407 产生 Z 实际运动脉冲并执行限位与运动约束。
2. **加工启动**：程序使用 `G0 X… Y…` 定位孔位，`M200 P… D…` 申请单孔穿孔；下位机停稳、检查原点/配方/深度/联锁后进入 `ARMED`。
3. **加工中**：STM32F407 独占 Z 轴，按放电间隙反馈进退；同时按选定位置反馈模式跟踪位置目标。PC 只显示与发送暂停、停止请求；手动点动命令被拒绝。
4. **结束/异常**：先关闭放电，再按安全条件退刀；仅在控制器报告手动模式后开始下一孔。通信失联或传感器故障由下位机独立处理，硬件急停不依赖 PC。

状态：`MANUAL_Z → ARMED → EDM_Z → RETRACT → MANUAL_Z`；任一关键错误进入 `FAULT`，人工复位并重新回零。

手动页是全机床操作入口，不承载找中计算。手动 XY 允许在确认工件 Z0 前进行定长点动；XY 目标快移要求 Z 读数不低于 0 mm，仍须由操作者核对实际安全高度。作业运行或暂停时锁定手动命令。冲液、旋转、放电输出只在控制器声明接入时启用；实机 STM32 输出协议仍待接线和固件确认。

### 铜管碰边与 G54 补偿

操作者将铜管外圆轻触工件边缘并记录当时铜管中心的 G54 工作坐标。设铜管实测外径为 `D`、半径为 `r=D/2`：

| 触碰边 | 实际工件边缘坐标 |
| --- | --- |
| X− / Y− 外侧 | 触碰时铜管中心坐标 `+ r` |
| X+ / Y+ 外侧 | 触碰时铜管中心坐标 `− r` |

单边设零时，选该边的实际边缘位置；双边找中时，取同轴两个实际边缘位置的平均数。两边使用同一铜管时，半径在中心计算中抵消。最后叠加该轴有符号附加补偿。页面预览应用前后当前读数，确认后由控制器单轴写入 G54，不移动机床。LinuxCNC 使用 `G10 L20 P1 X…` 或 `Y…`；写入后回读验证，原触碰记录清空。若外部修改 G54，也清空旧记录。此功能是找正偏置；加工路径的 G41/G42 刀具半径补偿尚未实现，也不会被静默套入 G 代码。

## 四、位置反馈选择

| 选择 | STM32F407 的位置反馈用法 | 说明 |
| --- | --- | --- |
| 编码器 | 跟踪电机/丝杠位置 | 不能直接看到传动间隙造成的工作轴误差 |
| 光栅尺 | 跟踪 Z 轴真实直线位置 | 5 µm/计数为当前默认值，可在设置中修改 |
| 光栅尺 + 编码器 | 编码器内层控制电机位置，光栅尺外层修正工作轴位置 | 驱动器仍是步进驱动；稳定性需实测整定 |

反馈模式是设备设置，不放进 G 代码逐孔切换。切换只允许在 Z 轴停稳且放电关闭时进行；模式变更后须重新确认 Z0。传感器故障不自动降级。详情见[位置反馈设置草案](feedback-settings-v0.1.md)。

## 五、G 代码约定

文件使用 UTF-8 `.ngc`，以 `%` 包裹，开头声明 `G21`、`G90`、`G54`。v0.1 只允许 `G0 X… Y…`、`M200 P… D…`、`M0` 和 `M2`。未知指令直接报错。`M200` 是上位机扩展，不能直接发给普通 GRBL/LinuxCNC 控制器；下位机接口负责转译。详情见[G 代码格式草案](gcode-format-v0.1.md)。

首页从已校验的 G 代码生成孔位、顺序路径和孔号。运行时以黄色标记当前孔、绿色标记完成孔，选中孔用蓝环区分；改动程序后保留上次校验的孔位图并提示重新校验。程序在暂停、等待 XY 或穿孔时锁定编辑。LinuxCNC 状态失联、XY 意外运动或超时会请求中止 XY 并要求 Z/放电急停；坐标失效时界面显示“—”。
